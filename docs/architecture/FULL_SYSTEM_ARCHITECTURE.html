1. Executive Summary and Core Mission

QuantAgent (code-named The Committee) is a reference multi-agent paper trading and decision intelligence platform. The software bridges quantitative algorithmic trading and large language model (LLM) financial reasoning without succumbing to common AI pitfalls such as look-ahead bias, hallucinated statistics, or uncontrolled execution.

INVARIANT 1
Zero-Leakage PIT
Strict as_of ≤ T_decision filtering enforced by runtime guards.
INVARIANT 2
$0.00 Replay
Deterministic backtests run offline using frozen multi-asset fixtures.
INVARIANT 3
Facts Over Narration
Numeric indicators are computed in code and locked against LLM alteration.
INVARIANT 4
Hard Risk Gates
Deterministic circuit breakers override and clamp agent sizing.

4. Layer 0: Market Data and Temporal Integrity

Layer 0 enforces point-in-time correctness. No historical dataset query, indicator snapshot, or news headline is allowed to leak forward information past the decision timestamp $T_{\text{decision}}$. 

sequenceDiagram
    autonumber
    participant D as Trading Daemon / Replay Runner
    participant G as TemporalGuard
    participant F as Frozen Fixture / DB
    participant S as Specialist Agent

    D->>G: queryBars(symbol, decisionTs)
    G->>F: Load raw historical bars
    Note over G: Check as_of <= decisionTs for every record
    alt All records valid (as_of <= decisionTs)
        G-->>D: Filtered point-in-time bars
        D->>S: Deliver AgentInput at T
    else Leaked record detected (as_of > decisionTs)
        G-->>D: Throw TemporalIntegrityViolation Exception!
        Note over D: Execution halted immediately. Zero look-ahead allowed.
    end
Figure 2: Point-in-time temporal assertion lifecycle.
As-Of Timestamping Rules
  • Daily OHLCV Bars: The official close of the New York trading session (16:00 America/New_York) is mapped to UTC (20:00Z during EDT, 21:00Z during EST). Any bar with as_of > now is discarded.
  • SEC EDGAR Filings: The official SEC acceptance timestamp (filedAt) is strictly used as the as_of boundary, never the historical periodEndDate.
  • Benzinga Financial News: Publication timestamp (publishedAt) acts as the as_of boundary.

5. Layer 1: Quantitative Analytics and Indicator Engine

Layer 1 computes deterministic numerical indicators in both Python (FastAPI microservice) and TypeScript (internal engine). LLMs are excluded from indicator computation.

Wilder's RSI (14) Mathematical Formula

Uses Wilder's Running Moving Average (RMA) with smoothing factor α = 1/14:

Gain_t = max(P_t - P_{t-1}, 0)
Loss_t = max(P_{t-1} - P_t, 0)
RMA_Gain = (RMA_{t-1} × 13 + Gain_t) / 14
RMA_Loss = (RMA_{t-1} × 13 + Loss_t) / 14
RSI = 100 - (100 / (1 + (RMA_Gain / RMA_Loss)))

Handles degenerate flat price windows by emitting neutral 50.0.

MACD (12, 26, 9) & Bollinger (20, 2) Mathematical Formula

TA-Lib compatible EMA seeding and population variance (ddof=0):

MACD_Line = EMA_{12}(Price) - EMA_{26}(Price)
Signal_Line = EMA_9(MACD_Line)
Histogram = MACD_Line - Signal_Line

BB_Mid = SMA_{20}(Price)
σ = sqrt(sum((P_i - Mid)^2) / 20) [ddof = 0]
BB_Upper = Mid + 2.0σ, BB_Lower = Mid - 2.0σ

6. Layer 2: Specialist Agent Domain Analysis

Four domain specialists extend BaseAgent, translating disparate financial inputs into structured AgentOutput envelopes:

Technical Specialist L1 Math + Rule Classifier

Computes composite mechanical score in [-1, 1] across RSI zones, MACD crosses, Bollinger Band bounds, and SMA trend alignments. Blends rule confidence with LLM commentary.

Sentiment Specialist Benzinga News Stream

Scans point-in-time financial headlines against a financial sentiment lexicon (35 bullish, 40 bearish terms). Calculates net score and generates market psychology analysis.

Fundamental Specialist SEC EDGAR XBRL Filings

Evaluates corporate balance sheets across three weighted pillars: Profitability (40%), Revenue Growth (30%), and Solvency / Leverage (30%). Stamped strictly at official filing date.

Polymarket Macro Specialist Gamma Prediction Odds

Synthesizes crowdsourced prediction market probabilities for Fed interest rate cuts, CPI inflation thresholds, and recession probabilities into macroeconomic regimes.

8. Layer 4: Deterministic Risk Gate and Capital Allocation

Layer 4 ensures that agent recommendations are mathematically bounded before reaching execution endpoints.

Risk Rule Trigger Condition Action When Breached
Confidence Threshold confidence < 0.50 REJECTED — Aborts trade; capital preserved in cash.
Drawdown Circuit Breaker drawdown > 15.0% from equity peak REJECTED — Halts all new buying until portfolio recovers.
Minimum Cash Reserve cashBalance < 10.0% of NAV REJECTED — Blocks orders that compromise liquidity.
Single-Position Exposure targetWeight > 20.0% of NAV MODIFIED — Clamps position weight to exactly 20.0%.
Volatility Ceiling annualizedVolatility > 60.0% MODIFIED or REJECTED based on volatility tier.

10. Frontend Web Observatory UI Architecture

The Web Observatory in apps/web/ provides an interface for inspecting decisions, tracking portfolios, and auditing model reasoning.

Portfolio & Real-Time Equity

Displays cash balance, portfolio equity, mark-to-market positions, and an interactive Recharts area chart with hairline crosshairs and WCAG twin tabular disclosure.

Experiment Observatory Tearsheets

Multi-series equity curves with shaded ±1σ variance bands, underwater drawdown profiles, and dense comparison tables (Sharpe, Sortino, Brier Score).

Decision Lineage DAG Inspector

Bar-by-bar stepper with keyboard arrow navigation. Displays raw input bars, EDGAR filings, rendered prompts, raw completions, and simulated trade fills.

Signals Radar & Daemon Control

Visual indicator gauges (Wilder RSI, MACD, Bollinger Bands), specialist stance cards, and start/pause/run-cycle controls for the trading daemon.

12. Engineering Invariants Summary

  • Point-in-Time Discipline: Every query enforces as_of ≤ T_decision. Leaked data causes immediate test termination.
  • Zero-Cost Offline Replays: Full backtest suites run without external API calls at $0.00 cost using frozen fixtures.
  • Deterministic Ground Truth: Mathematical indicators are calculated strictly in code and locked against LLM alteration.
  • Deterministic Risk Gates: Autonomous risk rules and position sizing cannot be bypassed by agent prompts.
  • Comprehensive Lineage Provenance: Every decision captures raw inputs, rendered prompts, model completions, and fills for auditing.
